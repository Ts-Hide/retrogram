# Retrogram（レトログラム）

写真やイラストを、レトロマシン規格の画像に変換するWebツールです。

- 対応機種：Atari ST / MSX2 SCREEN 5 / PC-6001mkII SCREEN 4 / PC-8801 V1モード / ファミコン
- 処理はすべてブラウザの中で完結し、画像が外部に送られることはありません
- ファミコンは、変換画像を実機で表示するためのROM（.nes形式）のダウンロードにも対応

## 使い方

`index.html` をブラウザで開くか、GitHub Pages の公開URLからアクセスしてください。
画像をドロップ（またはサンプルを選択）すると、その場で各機種規格への変換結果が表示されます。

## 構成

- `index.html` — アプリ本体（単一ファイル）
- `assets/` — サンプル画像5点

## 技術構成

- アプリ本体は単一の `index.html`（HTML / CSS / JavaScript）。外部ライブラリは使っていません
- 画像変換は Canvas API でブラウザ内に閉じて実行します（外部送信なし）
- 「まとめてZIP」は、無圧縮（STORE形式）のZIPをページ内で自前生成しています
- ファミコンの `.nes` は、NROM形式の静止画ビューアROMをブラウザ内で組み立てています
- ホスティングは GitHub Pages です

## 変換仕様（概要）

| 機種 | 解像度 | 色 |
|---|---|---|
| Atari ST | 320×200 | 適応16色（ST 512色から選択）/ Bayer 8×8 |
| MSX2 SCREEN 5 | 256×212 | 適応16色（512色から選択）/ Bayer 8×8 |
| PC-6001mkII SCREEN 4 | 320×200 | 固定4色セット（2種から選択）/ Bayer 8×8 |
| PC-8801 V1モード | 640×200 | デジタル8色固定 / Bayer 8×8 / 表示は4:3補正 |
| ファミコン | 256×240 | 背景色＋4パレット×3色 / 16×16ブロック割当 / ユニークタイル≤256 / ディザなし |
